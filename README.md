Dashboard de assinaturas do Xbox Game Pass desenvolvido em Excel para análise e visualização de dados.
# 📊 Dashboard de Vendas — Xbox Game Pass

## 🎯 Sobre o projeto

Projeto desenvolvido como parte de um desafio prático da DIO, com o objetivo de aplicar conhecimentos de Excel na organização, análise e visualização de dados relacionados às assinaturas do Xbox Game Pass.

A proposta consiste em transformar dados estruturados em informações visuais que facilitem a compreensão dos dados e apoiem a análise do negócio.

## 🗂️ Estrutura do arquivo

O arquivo Excel está organizado em quatro abas:

- **Assets:** reúne elementos visuais, como paleta de cores, logos e ícones.
- **Bases:** contém a base de dados das assinaturas e informações relacionadas aos planos e serviços adicionais.
- **Cálculos:** área destinada aos cálculos e à tabela dinâmica utilizados no projeto.
- **Dashboard:** apresenta o painel visual e os gráficos para consulta das informações.

## 📈 Dados utilizados

A base contém registros de assinantes e informações relacionadas a:

- Identificação do assinante;
- Nome;
- Plano contratado;
- Data de início da assinatura;
- Renovação automática;
- Preço e periodicidade da assinatura;
- Adesão e preços de serviços adicionais;
- Valor de cupom;
- Valor total.

## 🛠️ Ferramentas e recursos

- Microsoft Excel;
- Organização e estruturação de dados;
- Tabela dinâmica;
- Gráficos;
- Formatação e organização visual;
- GitHub;
- Markdown.

## 🚀 Como utilizar

1. Baixe o arquivo Excel disponibilizado neste repositório.
2. Abra o arquivo em uma versão compatível do Microsoft Excel.
3. Consulte a aba **Bases** para conhecer os dados utilizados.
4. Acesse **Cálculos** para consultar a área de apoio à análise.
5. Abra **Dashboard** para visualizar o painel.

Caso os dados sejam alterados, verifique a necessidade de atualizar as tabelas dinâmicas e os gráficos no Excel.

## 📚 Aprendizados

O projeto proporciona a aplicação prática de conceitos de organização de dados, construção de dashboards, visualização de informações e documentação técnica, utilizando o Excel como ferramenta de análise.
